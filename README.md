## Why open source?

- **Control** – run software on your own hardware and keep ownership of your data
- **Privacy** – avoid tracking and vendor data collection
- **No lock-in** – open formats and standards make migration easier
- **Cost** – no per-seat licensing fees
- **Transparency** – the code can be audited by anyone
